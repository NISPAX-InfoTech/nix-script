# NixScript

NixScript is proprietary software distributed by Nispax Official. This repository is the public release/download page; it does not contain the NixScript interpreter source code.

## Downloads

Download the prebuilt CLI for your platform from the [Releases page](https://github.com/NISPAX-InfoTech/nix-script/releases). Release assets include the Linux and Windows CLI packages and `SHA256SUMS.txt` for checksum verification.

GitHub automatically provides source archives for this repository. Those archives contain only the contents of this public release repository, not the private development repository or interpreter implementation.
